# Certifications

## 1. Kubernetes and Cloud Native Associate (KCNA)
- **Issuing Organization:** Cloud Native Computing Foundation (CNCF)
- **Status:** Completed
- **Description:** Demonstrates foundational knowledge of Kubernetes and the cloud-native ecosystem, including container orchestration, cloud-native architecture, and the CNCF landscape.

## 2. Prompt Engineering for Generative AI
- **Issuing Organization:** Udemy
- **Status:** Completed
- **Description:** Covers techniques for effective prompt engineering with large language models, including chain-of-thought prompting, few-shot learning, and practical applications.

## 3. AWS Certified Solutions Architect Associate (SAA-C03)
- **Issuing Organization:** Amazon Web Services (AWS)
- **Status:** In Progress
- **Description:** Validates the ability to design distributed systems on AWS, covering compute, storage, networking, database, and security services. Currently preparing for the exam.
